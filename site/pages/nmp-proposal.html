驚訝切開時間

語言模型靠「猜下一個字」學會語言。
影片模型應該靠「猜下一刻」學會時間。

方法名稱：NMP（Next-Moment Prediction，下一刻預測）。讓 LLM 在每張影格看完時，猜下一張影格長什麼樣子；再用它的「驚訝程度」找出事件邊界和時間方向。

觀察：影格位置沒人管

一筆訓練資料裡，97% 的位置沒有 loss

為什麼這很重要：2026 年的 Tracing the Arrow of Time 發現，逐張處理的影像編碼器本身不帶明顯的時間資訊，時間只能靠後面的 LLM 去整合。Gemma、Tarsier、LLaVA 系列都屬於這種架構。問題是，SFT 從來沒有直接要求 LLM 在影格位置上「把前後串起來」。

影片的「預測式」表徵訓練在 2026 年才出現，而且都是為了預測影片之後會發生什麼。在我查到的範圍內，還沒有人把訊號放在每一張已經看到的影格上，用來理解時間和切分事件。

方法：NMP

每看完一張，就從候選裡挑出「下一張」

為什麼要放「看過的」當陷阱

如果只跟別的影片比，模型隨便挑一張最像的就能過關。把「過去」放進候選，它就必須知道時間往哪個方向走。

為什麼目標用凍結的特徵

vision tower 本來就凍結，所以答案不會跟著模型一起變，模型沒辦法靠改答案作弊，也不會崩掉。

推論時要付什麼代價

完全不用。小 head 只在訓練時用；想算「驚訝曲線」時才開。

附贈：驚訝曲線

猜錯最多的地方，就是事件換場的地方

這對應認知科學的「事件切分理論」（Zacks et al., 2007）：人腦持續預測下一刻，預測突然失敗的地方就被感受為事件邊界。2023 年一篇聽故事的實驗還發現，「信念的改變量」（Bayesian surprise）比單純的「猜錯程度」更能對上人類標的邊界。這兩種驚訝都能在 NMP 裡算出來並直接比較。

① 無標註的事件切分

把驚訝的尖峰當成邊界，在 Kinetics-GEBD val 上算官方 F1。你已經有這份標註。

② 無標註的時間之箭

倒放的影片違反學到的物理規律，應該更難猜。比較兩個方向的平均驚訝，就能判斷正放還是倒放，不需要任何方向標註。

③ 驚訝導向取樣

先看 8 張，再把剩下的影格集中放在尖峰附近。這就是你原本「以 GEBD 邊界為中心取樣」的構想，只是測試時不需要 GEBD。

特別之處

不一定分數最高，但有五個別人沒有的特點

1

訊號放在沒人放的地方

佔序列 97% 的影格位置，第一次有了直接的時間訊號。

2

三個「不用」

不用標註、不用評審模型、不用生成答案。訓練成本幾乎等於 FFT。

3

密集，不是稀疏

每支影片有 N−1 個訊號，而 RL 是每題只有 1 個分數。

4

可以疊加

跟 T-GRPO、ArrowRL、Tarsier 的訊號放在不同層，可以先做 NMP 再做 RL。

5

看得見

驚訝曲線可以畫出來，還附帶事件切分、時間之箭、取樣三個新用途。

+

有理論根據

對應認知科學的事件切分理論，也能用人類標註的 GEBD 邊界直接檢驗。

要驗證的假設

七個可以被推翻的預測

H1
NMP 比 FFT 更懂時間：在時間敏感的 benchmark 上贏過 FFT，Kinetics 準確率不下降。
TempCompass、TVBench、Vinoground、AoTBench、SSv2（改成選擇題）；打亂 / 倒放後的分數落差
H2
猜「下一張」比猜「這一張」好：在時間題上 NMP 贏 B7，在靜態題上兩者差不多。
這是論文最關鍵的消融：證明進步來自「預測未來」，不是多了一個 loss
H3
每一張都猜，比只在最後猜好：NMP 贏 B8。
跟 IVT 的主要差別
H4
可以疊加：先 NMP 再 T-GRPO，勝過只做 T-GRPO。
NMP → T-GRPO vs B5
H5
驚訝會自己對齊人類的事件邊界：GEBD F1 明顯高於「相鄰影格特徵差」這個簡單基線。
Kinetics-GEBD val、官方 F1；參考線用無監督 GEBD 方法（UBoCo 等）
H6
零標註也能判斷時間方向：正放 / 倒放判斷高於 50%。
AoTBench 的方向題（ReverseFilm、UCF101）；對照 ArrowRL，它需要方向標註
H7
驚訝導向取樣接近「用 GEBD 真值取樣」，而且勝過均勻取樣。
同樣 16 張影格：均勻 vs GEBD 真值 vs 驚訝尖峰

就算 H1 的進步不大，只要 H2、H5、H6 成立，論文就有「新能力＋清楚機制」可以講。這也是這個題目「不一定分數最高、但有特別之處」的地方。

怎麼改你的 repo

一個新檔案，三個小改動

src/nmp.py（新）

小 head（每個預測距離一個 MLP）、找出每張影格在序列裡的區間、從 vision_tower 取凍結特徵（用 forward hook，不必重算）、InfoNCE、驚訝計算。

src/sft.py

compute_loss 裡加上 λ × NMP loss；另外記錄答案 loss、NMP loss、NMP 的 top-1 準確率。

src/training_modes.py

新增 full_nmp 模式：FFT 加上 head，head 的學習率照 projector。

src/ds_wrapper.py

選做：加入「只有影片、沒有答案」的樣本，這種樣本只算 NMP，讓你能用沒有標註的影片擴充。

config/full_nmp_ft.py ＋ scripts/full_nmp_ft.sh

λ、使用哪一層、預測距離 k、溫度 τ。

# 在 GemmaSFTTrainer.compute_loss 裡（示意，不是完整程式）
out   = model(**inputs, output_hidden_states=True)
h     = out.hidden_states[LAYER][0]                        # [序列長, d]；LAYER 例如 21（42 層的一半）
spans = frame_spans(inputs["mm_token_type_ids"][0])       # 每張影格的 (start, end)
f     = torch.stack([h[s:e].mean(0) for s, e in spans])   # 每張影格一個向量 [N, d]
z     = frame_targets.detach()                              # 凍結 vision tower 特徵，平均後做 L2 normalize [N, d_v]

nmp = 0.0
for k in (1, 2):                                         # 猜 t+1 和 t+2
    pred   = F.normalize(head[k](f[:-k]), dim=-1)           # [N-k, d_v]
    cand   = torch.cat([z, queue])                          # 候選：本片所有影格（含過去）＋其他影片的特徵佇列
    logits = pred @ cand.T / TAU
    nmp    = nmp + F.cross_entropy(logits, torch.arange(k, len(z), device=z.device))
loss = out.loss + LAMBDA * nmp

動手前先確認

Gemma 的圖片 attention 應該是「同一張圖內雙向、不同圖之間因果」。要確認第 t 張影格的 token 看不到第 t+1 張，否則模型等於偷看答案。

影格數

先沿用 8 張，每支影片就有 7 個訊號。要做 16 張時，每張的 token 數要降到 70～140，不然會超過 2,304 的長度上限。

風險與備案

可能出錯的地方，和出錯時怎麼辦

風險應對
表徵變好了，答題卻沒變好先看打亂落差有沒有變大；再疊加 T-GRPO 或少量時序 SFT；論文主軸放在「便宜、可疊加、新能力」
驚訝只抓到鏡頭晃動或剪接一定要跟「相鄰影格特徵差」比；按邊界類型分開分析；目標特徵可換成語意更強的（SigLIP2、DINOv2）
撞題（IVT、Imagine-Before-You-Predict 也做未來特徵預測）主打三個差異：每張影格都猜、目的是理解而不是預測未來、事件切分 / 時間之箭 / 取樣三個新用途；把 IVT 式當成消融 B8
倒放不一定比較難猜（可逆的動作）H6 只預期「高於 50%」；按動作是否可逆分組報告，而這個分組本身就是一個發現
RL baseline 在 Gemma 上不好跑先用小預算（例如 500 步）跑出趨勢；同時附上官方模型的數字當參考

備案 A：用「交換事件」取代「隨機打亂」

用 GEBD 邊界切出事件，只交換事件的順序，事件內部仍然連續。另外證明「隨機打亂可以靠畫面跳動認出來」是一種捷徑。最接近的是 Tarsier-2 的片段交換、TempCompass、TEMPLE。

備案 B：跨影片的動作階段對齊

把同一類的 Kinetics 影片兩兩配對，問「A 的第 i 張對應 B 的哪一張」，用已知的變速或裁切當作可驗證答案。最接近的是 TCC（2019）。風險比主案高。

  1. Surprise Carves Time: Next-Moment Prediction Teaches Video LLMs to Segment Events

逐張編碼的影片 LLM 必須在 LLM 內部整合時間，但 SFT 只在答案上計算 loss，佔序列絕大部分的影格位置幾乎得不到直接的訊號。我們提出下一刻預測（NMP）：LLM 在每張影格結束時，從包含「過去影格」的候選中挑出下一張影格的特徵。NMP 不需要標註、評審模型或 rollout，訓練成本幾乎等於 FFT，並能與 T-GRPO、ArrowRL 疊加。此外，NMP 的驚訝帶來三個新能力：驚訝尖峰對齊人類標註的事件邊界（Kinetics-GEBD）、正放與倒放的驚訝差異可零標註判斷時間之箭、驚訝導向的影格取樣。

撞題檢查：最接近的論文

動手前先讀這幾篇

IVT（2026/08）在「影片之後」的特殊位置預測未來影格的 patch 特徵，底座 BAGEL-7B，第一人稱資料。沒有分析事件邊界或時間之箭。最需要區隔。
Imagine Before You Predict（2026/06）解碼時生成連續的潛在影像片段來預測未來事件，再加 RL；底座 Qwen3-VL-8B。
Tracing the Arrow of Time（2026/05）逐張編碼器不帶時間資訊，瓶頸在 projector 和 LLM；他們的解法是換成影片編碼器。可當我們的研究動機。
ArrowGEV（2026/01）用 RL 做時間定位：對時間敏感的事件要分得出正倒放，不敏感的要一致。
TEMPLE（2025）用丟影格 / 打亂 / 倒放產生負例做 DPO，並依難度排課程。
Event-VStream（2026）用動作、語意和預測線索偵測事件邊界，用在串流影片上；是推論系統，不是訓練 LLM。
ROSS（ICLR 2025）讓 LMM 重建輸入影像的特徵；對應我們的消融 B7。
Prediction over Reconstruction（2026/06）在 world model 的潛在空間裡，「預測」比「重建」更能學到動作資訊。支持 H2。
Next-Event Prediction（2025）用文字預測接下來的事件，需要另外產生摘要當答案。
Bayesian Surprise（Cognitive Science 2023）「信念的改變量」比「猜錯程度」更能預測人類的事件邊界。
Perceptual Prediction（CVPR 2019）用預測誤差做自監督事件切分，但不是在 LLM 裡。
GEBD／UBoCoKinetics-GEBD benchmark，以及無監督 GEBD 的參考方法。
